# Performance

## Trigger
Use for latency, throughput, memory, or efficiency work.

## Steps
1. Clarify the bottleneck and success metric.
2. Invoke `coder` to diagnose and optimize.
3. Invoke `architect` only if structural redesign is needed.
4. Summarize bottleneck, changes, and trade-offs.
