# Refactor

## Trigger
Use when the user wants cleaner structure without changing intended behavior.

## Steps
1. Define the refactor boundary.
2. Invoke `architect` if structure is unclear.
3. Invoke `coder` to refactor.
4. Invoke `coder` again if behavior verification is needed.
5. Summarize the change and risk.
