# Security Audit

## Trigger
Use for security review, risk analysis, or hardening.

## Steps
1. Define the surface to audit.
2. Invoke `critic` for security analysis.
3. Invoke `coder` if fixes or hardening changes are needed.
4. Summarize risks, severity, and fixes.
