# Debug

## Trigger
Use when the cause is unclear or the failure is intermittent.

## Steps
1. Clarify the symptom and environment.
2. Invoke `coder` to trace and diagnose.
3. Invoke `coder` again if extra reproduction or regression coverage is needed.
4. Summarize cause, fix, and confidence.
