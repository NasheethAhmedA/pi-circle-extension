# Bug Fix

## Trigger
Use for concrete defects with a desired fix.

## Steps
1. Clarify the symptom and reproduction.
2. Invoke `coder` to diagnose and fix.
3. Invoke `coder` again if extra verification or regression coverage is needed.
4. Summarize the fix and remaining risk.
