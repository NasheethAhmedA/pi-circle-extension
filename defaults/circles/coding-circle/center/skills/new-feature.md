# New Feature

## Trigger
Use when the user wants a new feature built.

## Steps
1. Clarify scope and constraints.
2. Invoke `planner` or `architect` if design is needed.
3. Invoke `coder` to implement.
4. Invoke `coder` again if explicit test-writing or verification is needed.
5. Summarize what shipped and what remains.
