# Refine Agent

## Trigger
Use when an existing agent should be improved.

## Steps
1. Identify whether the problem is scope, clarity, overlap, prompt weight, skill quality, or reusable script ownership.
2. Keep the prompt concise and move deep procedure into agent-owned skills.
3. Invoke `critic` for a targeted assessment.
4. Invoke `architect` if the agent boundaries or internal structure need redesign.
5. Invoke `coder` to rewrite the files.
6. Summarize the changes and the expected benefit.
