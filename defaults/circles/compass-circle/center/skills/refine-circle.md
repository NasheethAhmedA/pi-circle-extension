# Refine Circle

## Trigger
Use when an existing circle should be improved rather than created from scratch.

## Steps
1. Identify whether the problem is routing, prompt clarity, skill ownership, script ownership, roster design, or workflow shape.
2. Check that the center remains circle-specific and that reusable specialists stay generic.
3. Invoke `critic` for a targeted assessment of overlap, ambiguity, and unnecessary center depth.
4. Invoke `architect` when the circle structure needs redesign.
5. Invoke `coder` to apply the changes to the user-owned circle files.
6. Validate the result and summarize the expected improvement.
