# Idea Exploration

## When This Applies
Use for brainstorming, option generation, reframing, and early exploration.

## Process
1. Clarify the space to explore.
2. Generate multiple distinct directions.
3. Surface surprising or non-obvious options.
4. Converge to the strongest candidates.
5. Return concise options and reasoning, then invoke `center`.

## Anti-Patterns
- ❌ Repeating obvious ideas only
- ❌ Wandering without converging
- ❌ Confusing novelty with usefulness
