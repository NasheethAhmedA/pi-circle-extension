# Documentation

## When This Applies
Use for README files, design docs, handoffs, guides, and structured notes.

## Process
1. Identify audience, purpose, and existing doc style.
2. Extract settled facts, constraints, and open questions.
3. Organize into clear headings and short paragraphs.
4. Mark unfinished areas honestly.
5. Return or write the document, then invoke `center`.

## Anti-Patterns
- ❌ Mixing final decisions with speculation
- ❌ Dense, unstructured walls of text
- ❌ Omitting assumptions or unresolved issues
