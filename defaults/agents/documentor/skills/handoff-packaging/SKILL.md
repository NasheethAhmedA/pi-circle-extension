# Handoff Packaging

## When This Applies
Use for export packs, context handoffs, summaries for later work, or shareable structured outputs.

## Process
1. Gather the settled facts, decisions, open questions, and next steps.
2. Remove noise and repetition.
3. Structure the handoff for fast reuse.
4. Mark uncertainty clearly.
5. Return the packaged handoff, then use the `invoke` tool with `agent: "center"`.

## Anti-Patterns
- ❌ Mixing final decisions with speculation
- ❌ Omitting unresolved questions
- ❌ Dumping raw notes without structure
