# UX Analysis

## When This Applies
Use for UX review, flow analysis, usability critique, or experience gap finding.

## Process
1. Identify the user goal and path.
2. Examine friction, ambiguity, inconsistency, and missing feedback.
3. Prioritize the biggest UX failures and confusing transitions.
4. Return concise findings and improvement directions, then use the `invoke` tool with `agent: "center"`.

## Anti-Patterns
- ❌ Pure aesthetic commentary
- ❌ Generic UX clichés with no concrete failure point
- ❌ Ignoring the user goal and task flow
