# Critique Framework

## When This Applies
Use for review, stress-testing, gap-finding, and quality evaluation.

## Process
1. Identify the artifact and its intended goal.
2. Check assumptions, constraints, contradictions, and missing evidence.
3. Prioritize the highest-risk issues.
4. Distinguish blockers from improvements.
5. Return concise findings and next actions, then invoke `center`.

## Output Shape
- Critical issues
- Important weaknesses
- Nice-to-have improvements
- Open questions

## Anti-Patterns
- ❌ Vague negativity
- ❌ Treating preferences as defects
- ❌ Long essays without prioritization
